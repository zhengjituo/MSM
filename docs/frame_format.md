# 帧格式说明

## 物理帧结构（1152 字节/帧）

| 偏移 | 大小 | 内容 |
|------|------|------|
| 0–1 | 2B | 帧头魔术字 `0xEB 0x91` |
| 2–16 | 15B | 保留 |
| 17–20 | 4B | **TrigID**（U32，大端） |
| 21–63 | 43B | 保留 |
| 64–1087 | 1024B | 波形数据（无业务含义） |
| 1088–1151 | **64B** | **帧尾（Trailer）** |

### 帧尾（64 字节，偏移 1088–1151）

| 偏移 | 大小 | 字段 | 说明 |
|------|------|------|------|
| 0–1 | 2B | 尾魔术字 `0xEB 0x92` | |
| 2–7 | 6B | **BunchID**（U48，大端） | 采集时间戳，每帧 +10 |
| 8–11 | 4B | **Sum**（U32，大端） | 光强值（各通道） |
| 12–23 | 12B | 保留 | |
| 24–31 | 8B | **X**（DBL，大端） | 通道 1 仅有的 X 位置 |
| 32–39 | 8B | **Y**（DBL，大端） | 通道 1 仅有的 Y 位置 |
| 40–47 | 8B | **I**（DBL，大端） | 通道 1 仅有的强度（= 四通道 Sum 均值） |
| 48–63 | 16B | 保留 | |

## MSM1 二进制传输协议

物理帧经 `test_bench_e2e.cpp` 提取后以 MSM1 格式发送到服务端。

### 报文头（28 字节）

| 偏移 | 大小 | 字段 | 说明 |
|------|------|------|------|
| 0–3 | 4B | `magic` | `"MSM1"` |
| 4–5 | 2B | `hdrLen` | `= 28` |
| 6–7 | 2B | `numCh` | 通道数（当前 4） |
| 8–11 | 4B | `batchSize` | 每通道帧数（当前 10000） |
| 12–19 | 8B | `sentSeq` | 发送端批计数器 |
| 20–27 | 8B | `tUs` | 发送时刻（μs） |

### 每通道数据块

报文头之后，每个通道依次写入：

```
uint16_t numVars    // 该通道的变量数
for each var:
  uint8_t  type      // 0=U32, 1=U64, 2=DBL
  uint8_t  nameLen
  char     name[nameLen]
  uint8_t  data[type[batchSize]]  // 小端序
```

### 当前变量集

| 通道 | 变量 |
|------|------|
| 0 | `trig_id`(U32) + `bunch_id`(U64) + `sum`(U32) + `x_pos`(DBL) + `y_pos`(DBL) + `intensity`(DBL) |
| 1–3 | `trig_id`(U32) + `bunch_id`(U64) + `sum`(U32) |

每批二进制包大小：~859KB（6+3+3+3 变量 × 10000 帧）。

## 服务端流程

```
POST /api/data (binary MSM1) → 存储原始二进制，解析头部的 t_us 计算间隔
GET  /api/data               → 解析二进制为 JSON，返回给浏览器
GET  /                       → 返回仪表板 HTML
```

- 服务端用 `ThreadingHTTPServer` 多线程处理请求
- POST 约 2ms（仅存二进制）
- GET 约 30ms（批量解包 15 个变量 × 10000 帧 + JSON 序列化）
- 浏览器每 100ms 轮询

## 仿真数据特性

| 变量 | 范围 | 变化 |
|------|------|------|
| TrigID | U32，从 1,000,000 递增 | 每帧 +1，32 位自然溢出 |
| BunchID | U64，从 10,000,000 递增 | 每帧 +10 |
| Sum | 约 10–50（U32） | (ch+1)×10 ±5 正弦缓变，每批 seq 偏移 |
| X | 0.1–0.9（DBL） | 通道 1 仅有的位置，缓慢漂移 |
| Y | 0.1–0.9（DBL） | 通道 1 仅有的位置，缓慢漂移 |
| I | DBL | 四通道 Sum 均值：`(s0+s1+s2+s3)/4` |
