# 工作移交文档 (2026-06-16)

## 项目状态

MSM 框架，C++17 + CMake。三种跨进程/跨网络通讯机制已验证通过：

### 1. 通讯架构

| 层 | 协议 | 端口 | 用途 |
|----|------|------|------|
| DataChannel | 裸 TCP | 9100 | 高速批量数据（11.52MB/batch） |
| MSMGateway DEALER/REP | ZMQ | 5555↔5565 | 控制消息 (DATA_READY/DONE) |
| MSMGateway PUB/SUB | ZMQ | 5557↔5567 | 广播 |

### 2. 性能

| 场景 | 吞吐 | 瓶颈 |
|------|------|------|
| localhost | **3.5 GB/s** | CPU/内存 |
| 跨网 1 Gbps | **111 MB/s** | 网卡 |

### 3. 核心改动 (commit a978007)

**module_datachannel/** (新):
- `DataChannel` — TCP 封装（send/recvAll）
- `DCProducerModule` — 批量发送 + TCP_INFO 预检 + 5s 超时 + 失败重联
- `DCConsumerModule` — 预分配 buffer 接收 + 重联
- `dc_alpha`/`dc_beta` — 可执行入口，JSON 配置驱动

**module_core/**:
- `Module::runLoop` — 条件变量唤醒（`post()` 时 `notify_one()`），每 100 条消息强制 idle
- `MSMGateway::runSUB` — 广播接收日志

### 4. 配置示例 (Alpha - 本机)

```json
{
  "module": "DCProducer",
  "dc_producer": {"data_port": 9100, "frames_per_batch": 10000, "frame_size": 1152, "total_batches": 100},
  "gateway": {
    "rep_port": 5555, "pub_port": 5557,
    "peers": [{"name": "Beta", "endpoint": "tcp://对方IP:5565"}],
    "subscriptions": [{"name": "Beta", "endpoint": "tcp://对方IP:5567"}]
  }
}
```

Beta 端 `dc_consumer.data_host` 指向 Alpha IP。
